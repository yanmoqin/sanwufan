# 三五反线上对战 v1.2.2

三五反是一款四人结对的扑克牌游戏，对坐的两人为搭档。庄家方守分，闲家方抓分，闲家拿到40分及以上即可上台。

支持四人好友联机和单人练习。电脑或手机浏览器即可上桌，支持公开底牌、出牌回看、聊天互动、30秒出牌计时，以及四家同意的投降和整场战绩结算。

## 下载试玩

[下载 Windows 便携试玩包](https://github.com/yanmoqin/sanwufan/releases/latest)

在下载页面的 **Assets** 中选择 Windows 试玩 ZIP 包，完整解压后运行。开桌电脑需要 Windows 10/11 64位，无需安装 Python；其他玩家只需要浏览器。

## 开始游戏

- **单人练习**：双击 `启动牌桌.cmd`，在打开的服务管理页点击“打开牌桌”。
- **四人联机**：双击 `启动远程试玩.cmd`，打开牌桌并创建好友房，将房间邀请链接发给朋友。四人全部准备后开始游戏。

联机时，开桌电脑需要保持运行和联网，并保留服务管理页。关闭最后一个服务管理页约15秒后，本次服务会退出；关闭普通牌桌页面只会断开自己的连接。临时邀请网址可能在重新启动后变化。
