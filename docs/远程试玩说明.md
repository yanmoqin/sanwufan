# 三五反远程试玩

## 开一桌

1. 把远程试玩包完整解压到一个文件夹，双击 **启动远程试玩.cmd**。
2. 等待浏览器打开 **服务管理页**，点击 **打开牌桌**，输入昵称，再点击 **创建好友房**。打牌时保留管理页。
3. 点击顶部 **房间**，再点 **复制邀请**，把房间邀请链接发给三位朋友。
4. 朋友在手机或电脑浏览器打开链接，输入昵称加入；四人准备后开始发牌。

最新包为 `三五反远程试玩包_v1.0.zip`。本机练习双击 `启动牌桌.cmd`，默认使用8766端口和独立本机存档，占用时自动选空闲端口。本机或远程启动器已运行时，再次双击会打开该服务的管理页。

只有开服务的人需要压缩包，朋友只需要浏览器。包内带便携 Python 和 Waitress，无需安装 Python、注册账号、购买域名或服务器。适用于 Windows 10/11 的64位电脑。所有运行组件都随包提供。

在微信收到链接后，可先直接打开；如果微信没有正常显示牌桌，用右上角菜单选择浏览器打开。微信内实际可用性需要在朋友的设备上验证。

## 试玩时

界面版将座位、出牌、分数、公开底牌与自己的手牌放在同一张牌桌上。点手牌选中，再点出牌或当前阶段的操作按钮；“提示”只帮你选牌，不自动提交。手机竖屏按六列展示手牌，横屏使用横排手牌；无需切换页面来找自己的牌。

顶部 **回看** 查看已结束的轮次，**菜单** 提供玩法速览、牌局动态、全屏和单人托管；**房间** 提供邀请、个人恢复码和离房。点分数可看两队详情，点其他人的头像可互动或执行房主管理。手牌旁的 **特殊牌** 打开亮反选择与杠提示，四张同点数时可直接采用推荐亮法，或展开 **其他亮法**。

尚无人亮主时每张间隔0.4秒，首局自动亮出最先收到的2。有人亮主后立即发完剩余手牌，不再播放发牌动画。三张3或5在手牌发完后自动亮反；四张时由本人选择，默认推荐三反保留主花色3、五反保留方片5，也可以保留四张、不亮反。特殊牌提示只显示本人手牌；点杠提示只选牌，不自动出牌。

亮反截止于庄家扣牌提交前，确认继续后仍可以补亮。庄家拿底所得的3、5也可以组成反：凑成三张自动亮出，四张仍由本人选择。扣牌提交后不能再亮反；贡牌交换取得的牌不能组成反。进贡尚未完成时，补亮反产生免贡会取消未提交交换；交换已经完成后补亮反保留已完成交换。

已亮的三反、五反会显示在对应玩家头像旁，全桌都能看到实际亮出的三张牌；未亮的第四张3按普通3使用。庄家扣下6张底牌后，底牌向全桌公开。“回看出牌”每行一轮，纵向排列本局已完成的四家出牌、赢家和得分，无需切换轮次，进入下一局后清空。

点击其他玩家头像，可扔鸡蛋、西红柿、送花、鼓掌，也可关闭互动动画；单人练习也支持对自动玩家互动。房主在开局前、结算后可请离玩家，需确认；请离后全桌重新准备，该玩家当前身份需等房主重新开桌后才能再次加入。

保持电脑运行、联网，不要休眠。关闭最后一个服务管理页约15秒后，会停止本次启动的牌桌、公网通道和启动窗口；刷新管理页可重新连接，关闭普通牌桌页面不停止整桌。也可以点管理页的“结束本次服务”，或在启动窗口按 Ctrl+C 停止。再次启动会读取原存档，公网网址可能变化。管理页仅在服务电脑本机提供，不随公网通道公开。`--no-browser` 启动在管理页首次连接前不会自动退出。

网址也会写入包目录的 `试玩网址.txt`。进入房间后，从页面复制邀请才能带上房间号。各人使用自己的浏览器；同一浏览器的多个标签页会共享身份。

## 网址变了，怎么回来

入座后，点击顶部 **房间**，展开 **保存我的恢复码**，把自己的码单独保存。别人拿到恢复码就能接管你的座位，不要发到群里。只分享房间邀请。

短暂断网、同一网址刷新：使用原浏览器即可继续。启动通道重新生成网址后：打开新的网址，展开 **恢复之前的座位**，粘贴个人恢复码，找回昵称、座位和手牌。恢复成功会更换个人恢复码，请保存新的码，旧码随即失效。

房主重新启动后，需要把新网址发给大家。房间无人访问两小时会过期，停机时间也计入；过期后重新建房。存档在 `data/remote/games.sqlite3`，与本机练习服务的存档独立。不要删除 `data`，也不要把自己使用后的整个文件夹发给朋友；分享原始压缩包。

## 连接失败

可以重新双击启动。程序会在网址通过 HTTPS 健康检查后才显示邀请；连接失败不会把仅生成、尚未可用的网址当成成功。不要关闭防火墙或修改路由器端口。启动窗口会指出错误；详细日志在 `data/remote/tunnel.log` 和 `game.log`。

当前采用 Tunnelmole 的免账号 HTTPS 通道。重新启动后网址可能变化，适合小范围试玩；不同地区和运营商仍需实测，免费通道不保证持续可用。通道结束或网址发生变化时，程序会明确提示重新启动并撤下旧邀请。来源：[Tunnelmole 官方介绍](https://tunnelmole.com/)。

## 开发者说明

`sanwufan.remote` 在本机空闲端口启动现有 Waitress 服务，根据通道实际生成的 HTTPS 源地址配置 Host、Origin 和安全会话 cookie；保留原有校验。通道适配器使用经过证书验证的 WSS 连接，只向指定的本机游戏端口转发请求，不使用 SSH、私钥或其他账号。保留浏览器传来的 Host、Origin 和会话 cookie，不代替玩家身份。Windows Job Object 保证关闭启动器后，其所属牌桌和通道进程一并结束。

内置 Python 来自 python.org 官方64位嵌入包；Waitress 与 websocket-client 来自 PyPI，通道适配器依据 Tunnelmole 开源协议实现，许可证随包提供。组件来源与校验值见包内 `组件来源.json`，全部打包文件校验值见 `MANIFEST.sha256`。
